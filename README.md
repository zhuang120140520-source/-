# 周末游玩预约

基于现有静态网页调整的周末出游安排工具，保留原来的暖色卡片和多语言切换。

## 页面流程

1. 首页询问「周末去哪里玩？」，填写游玩时间；时间段下面可点击「这周算了」。
2. 选择活动，支持多选和自定义。
3. 先选择吃午饭、晚饭、两顿都吃或不吃饭，再进入「吃什么」。不吃饭会跳过美食选择。
4. 「你想去哪里」：选择新加坡或出国，并填写游玩地点。
5. 生成可复制的周末游玩清单，或者这周不出游的结果。

原有心情步骤已经删除，页面、四种语言、指南和生成清单均已更新。

## 使用和上传

双击 index.html 可以打开。也可在此目录运行 python -m http.server 8000，访问 http://localhost:8000。

上传时，把 index.html、app.js、i18n.js、guide.html、about.html、404.html 放在网站同一目录；保留所有文件的相对位置。主页需要同时替换两份 JavaScript 文件。

这是纯前端清单工具。填写内容只用于当前页面，刷新后会清空。语言偏好保存在浏览器本地。样式与图标沿用原站的 CDN，初次加载需要网络。

## 分享和反馈

当前版本不会自动接收或通知对方的填写结果。对方填写后，点击「复制清单」，通过微信、WhatsApp 或其他聊天工具发回给你。

本地预览地址（127.0.0.1 或 localhost）只用于本机查看，不能发给别人打开。要让对方在线填写，需要先把网站发布到 GitHub Pages 或其他公网托管，再把公开网页链接发给对方。当前账号没有原仓库写入权限，因此原网址尚未更新。
