# 周末游玩预约 · 双人版

前端发布于 GitHub Pages，房间同步服务由 Sites + D1 托管。页面没有预算、具体地点或恋爱元素。

## 六个页面

1. 创建或加入两人房间，复制邀请链接。
2. 填写具体开始、结束时间，匹配时间交集；选择本城市 / 出城游玩，也可以选“这周算了”。
3. 活动投票：想玩 / 可以 / 不想玩，可自定义活动。
4. 午饭 / 晚饭 / 不吃饭；每人最多五种美食，按喜好排序。
5. 共同匹配、冲突补选、抽签、每人一次换签与双方确认。
6. 最终安排、复制结果、小红书搜索关键词。

## 发布静态页面

把这个文件夹中的文件上传到仓库根目录，保留 `index.html`、`app.js`、`config.js`、`style.css` 在同一级。GitHub 仓库的 Settings → Pages，选择 Deploy from a branch，main，/(root)。不要把 zip 压缩包作为页面上传。

`config.js` 中的 WEEKEND_API 指向已部署的房间服务。它不是密钥。如果更换 GitHub 账号或域名，需同时调整房间服务的 CORS 来源。

## 同步和隐私

完整邀请链接中包含入房凭证。前端保存在浏览器的参与者凭证用于访问各自选择，请勿清理后再依赖恢复。每个房间只能加入两人。

双方提交前，服务不会将另一人的答案发送到当前设备。提交后显示交集；无美食交集时提供两人美食名称供补选。服务保存的称呼、选择和结果不会写入这个公开仓库。

房间从所选第一天起四天后停止访问，此版本没有定时清理任务。详见 about.html。
